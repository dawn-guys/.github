# Dawn Guys

네 명이 함께 흩어진 공연 정보를 한곳에 모으는 서비스 **쇼모아**를 만들고 있습니다.

## 쇼모아

> 전국 공연과 공연장을 한 곳에서 발견하고, 관심 공연을 저장해 개인 캘린더와 외부 예매처까지 연결하는 공연 정보 플랫폼

<!-- 시연 화면(스크린샷 또는 GIF)을 여기에 넣는다. 프론트엔드 담당 -->

### 해결하려는 문제

연극·뮤지컬·무용·국악·콘서트 등의 공연 정보는 공연장, 예매처, 검색 포털, SNS에 흩어져 있습니다. 공연 제목을 알면 검색할 수 있지만, "이번 주말에 갈 만한 공연"이나 "집 근처 극장에서 하는 공연"처럼 **탐색하는 질문**에는 답을 얻기 어렵습니다. 관심 공연이 많아지면 공연 기간을 따로 기록해야 하고, 공연장별 라인업을 한눈에 비교하기도 어렵습니다.

쇼모아는 이 과정을 **발견 → 비교 → 저장 → 일정 관리 → 예매처 이동**의 한 흐름으로 줄입니다. 공연 데이터는 공연예술통합전산망(KOPIS)에서 매일 모읍니다.

| 단계 | 사용자 경험 |
| --- | --- |
| 발견 | 키워드와 상태·장르·지역·기간 필터로 검색하고, 찜이 많은 인기 공연을 봅니다. |
| 비교 | 포스터, 기간, 공연장, 장르를 한 화면에서 비교합니다. |
| 저장·일정 관리 | 관심 공연을 찜하면 공연 요일과 공휴일이 표시된 월별 캘린더에서 다시 확인합니다. |
| 예매처 이동 | 공연 상세에서 공식 외부 예매처로 바로 이동합니다. |
| 지역 탐색 | 지도에서 주변 공연장과 현재 라인업을 확인하고, 역·랜드마크 이름으로도 찾습니다. |
